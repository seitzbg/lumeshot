Initial Lumeshot release for macOS.

- Capture screenshots, annotate images, and record the screen.
- Configure upload destinations, including Picsur, and copy shareable links.
- Manage preferences and global capture shortcuts in a dedicated Settings window.
- Install from a Developer ID signed and notarized DMG.
