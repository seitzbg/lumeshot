One change, to how the annotation editor's window is sized.

## The editor opens larger and remembers your size

The editor window opened small enough that marking up a capture felt cramped, and
if you resized it the size was forgotten by the next capture.

It now opens at a generous default — up to 1200×780, capped to fit your screen and
never smaller than 760×480 — and it **remembers the size and position you set**, so
a one-time resize sticks for the next capture and the next launch. The window has
always been resizable; this just gives it a roomier starting size and makes your
own size stick.
