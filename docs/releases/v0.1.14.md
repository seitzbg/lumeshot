Guard rails for upload destinations, after a screen recording failed to upload for a
reason nothing explained.

- Uploaders that only accept images — Picsur and Imgur — are now marked as such. If your
  screen recordings would be sent to one, Lumeshot says so under Uploads instead of
  letting the server reject the video with a generic error. A recording upload to an
  image-only host now fails immediately, naming the host and the setting to change.
- Uploaders you have not tested are marked "not tested", with a reminder when one is in
  use. Testing an uploader records the pass; editing it clears that again. Nothing is
  blocked — a correct configuration still saves while the server is unreachable.
- Failed recording uploads now write the reason to `~/Library/Logs/Lumeshot.log`. It
  previously appeared only in a notification, which left nothing to look at afterwards.
