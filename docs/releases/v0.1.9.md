Editor fixes and a new update check.

- Blur and pixelate now **stack** when they overlap. Layering them composes, instead of
  the last one replacing what is underneath. This changes how overlapping effects render
  compared with earlier versions; effects over separate regions are unaffected.
- The editor stays responsive while dragging over a blurred or pixelated region.
- Text no longer reflows when you finish typing it. The editing font now matches the one
  it is saved with.
- Stroke colour and width apply to the annotation you have selected, not only to newly
  drawn ones. Changing a colour is a single undo step rather than one per movement of the
  colour wheel.
- New **Check for Updates…** in the Lumeshot menu tells you when a newer release is
  published and links to it. It reports only — it does not download or install anything,
  and it stays quiet on builds you compile yourself.
- The Screen Recording permission window no longer clips its instructions at larger system
  text sizes.
