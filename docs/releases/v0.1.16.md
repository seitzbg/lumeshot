No changes to the app. This release is identical to v0.1.15 and exists so the
automatic updater has something to update *to*.

v0.1.15 introduced Sparkle, but a copy of it finds only its own entry in the
feed, so nothing about the download-and-install path could be exercised until a
newer release existed. This is that release.

If you are reading this inside Lumeshot's update window, the part that needed
testing has already worked: the app checked the feed, found this version, and
fetched these notes. Installing it exercises the rest — verifying the signature,
replacing the app in place, and relaunching.

If you are on v0.1.15 there is nothing to gain by updating, beyond confirming
that updating works.
