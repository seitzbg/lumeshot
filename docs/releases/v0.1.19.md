One change, to make the annotation editor's tools easier to recognise.

## The editing tools are now a labelled rail

The editor's drawing tools used to be a row of icon-only buttons along the top,
sharing space with the colour, width and finish controls — you had to hover each
one to find out what it did.

They now sit in a vertical rail down the left side of the editor, each shown as an
icon **and** its name — Select, Rectangle, Ellipse, Line, Arrow, Freehand, Crop,
Text, Highlighter, Blur, Pixelate, Step — with the active tool highlighted. The
top bar keeps the colour, stroke width, undo/redo/delete and the Cancel / Copy /
Save / Upload buttons. Nothing about what the tools do has changed; they are just
easier to tell apart. With the tools moved out of the top row, the editor window
also opens at a more compact size again.
