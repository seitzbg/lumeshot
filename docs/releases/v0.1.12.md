- Screen recordings can upload to a different destination from screenshots. Choose one
  under Uploads → Screen recordings. Useful when your image host does not accept video —
  Picsur, for one, rejects it outright. Left unset, recordings go wherever screenshots go,
  which is how earlier versions behaved.
- The recording timer in the menu bar is no longer cut off. It previously showed as a bare
  colon with no digits.
